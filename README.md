# Semantic-Firewall-for-MAVLink

Modern autonomous UAVs rely on a bifurcated architecture, separating the Flight Controller (managing real-time physics) from the Companion Computer (handling high-level processing, AI, and communications). These systems communicate via the MAVLink protocol over a serial connection. If an adversary compromises the internet-facing Companion Computer, they gain authorized access to this MAVLink stream. This allows them to bypass standard cryptographic signing and inject "Control-Aware Attacks." These attacks consist of mathematically valid but physically malicious parameter changes—such as subtle PID detuning or EKF estimation alterations—that destabilize the drone's attitude control without triggering native flight controller failsafes.

This project aims to develop and evaluate a lightweight Intrusion Detection System (IDS), acting as a "semantic firewall" between the Companion Computer and the Flight Controller. Using statistical modeling (such as Isolation Forests) or physics-based rulesets, the IDS will verify the physical legitimacy of MAVLink commands in real-time before they reach the flight controller. The project will generate a novel dataset of baseline and anomalous MAVLink traffic using ArduPilot Software-In-The-Loop (SITL) and Gazebo simulations. Finally, Hardware-In-The-Loop (HITL) validation using a Raspberry Pi and Pixhawk flight controller will be conducted to measure the latency impact and performance of the firewall on the serial connection.
